## 风险与预案

| 风险 | 触发信号 | 预案 |
|---|---|---|
| remerge-diff 在真实仓库噪声大（实测 357 merge 中 34 有 payload） | M2 fixture 之外误报 | 三分 hunk + `RESOLUTION` 默认不报；降噪规则逐条配 fixture |
| 冲突树逐 blob 对比出现大量"合法差异" | blob_fidelity 偏低 | 以 `mechanical_conflict=true` 单独分栏，不混入 SMUGGLED |
| `merge-tree` 写对象破坏"只读" | `.git/objects` 数量变化 | `TempObjectDir` + 测试断言前后计数不变（M0 已锁） |
| 3.8 无 `tomllib` | gate 实现 | 自写受限子集 + `toml_unsupported` 显式 |
| Windows 路径/编码 | CI 首跑 | 入口 `_ensure_utf8_stdio` + 子进程显式 `encoding="utf-8"` + 路径判据用 `realpath` |
| 真实仓库样本缺失 | M2 bench 无大仓库 | 用 fixture + 本机可用仓库；bench 如实标注样本量 |
