### 4.1 打包口径（`tools/`、`data/` 的处理）

- **`[tool.setuptools]`**：`package-dir = {"" = "src"}` + `packages.find where=["src"]`。
  实测 wheel 内容（`mergefidelity-0.1.0-py3-none-any.whl`）**只有** `mergefidelity/*.py` 与
  `dist-info/*`（含 `LICENSE` / `entry_points.txt`）——**不含** `tools/`、`data/`、`bench/`、`docs/`、`plan/`。
- **`tools/` 与 `data/` 不入包**：它们是开发期资产（fixture 生成器与 golden），不是运行时分发物；
  运行时零依赖、只读 `.git`，`pip install mergefidelity` 后即可对**任意**仓库使用。
- **手工源码包**（D3 定案）是 `git archive v0.1.0` 的**整树**（含 `plan/`、`data/`、`tools/`、`bench/`、`docs/`），
  与 wheel 的分发面不同：前者给"想看全部证据/复现 fixture"的人，后者给"只想装来用"的人。
